Projects and invoices

Set the site type for each project, and mark a project completed when the job is done. Archive an invoice to take it out of the stock figures without deleting anything; you can restore it later. Whatever is still in the store for a completed project becomes leftover stock that any new site can use.

Import an invoice

Choose the supplier's invoice PDF. The lines are read into a table you can correct before anything is saved. Cable and duct quoted per 100 m are converted to metres.

Backup

A backup is one zip file holding everything: stock, handovers, the asset register, photos and signed slips. Download one regularly and keep it somewhere safe, such as OneDrive.

Restore from a backup

Restoring replaces everything on the site with what is in the backup file. Anything entered after that backup was made is lost, so only do this to recover from a problem.
